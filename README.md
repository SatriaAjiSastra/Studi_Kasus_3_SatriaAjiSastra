# Studi_Kasus_3_SatriaAjiSastra

## Penjelasan Singkat Kode Program
Program Python ini untuk sistem peminjaman buku di Perpustakaan Fakultas Teknik:

Struktur Data Tuple dan List Daftar stok buku perpustakaan disimpan menggunakan Tuple karena datanya bersifat tetap (tidak bisa diubah) keranjang pinjaman menggunakan List karena dinamis, sehingga pengguna bisa menambah buku pakai append dan menghapusnya pakai remove
Sistem Perulangan Menu program dibungkus dengan perulangan while True agar menu terus muncul berulang-ulang sampai pengguna memilih opsi selesai break
Logika Validasi Program menggunakan kondisi if-else serta operator in untuk mastikan apakah judul buku yang diketik pengguna tersedia di dalam data perpustakaan atau di dalam keranjang pinjaman.
